CODESTORM V18

Doctor profiles are treated uniformly. Doctor identity does not change permissions: every doctor can perform the same workflow when the same relationship exists with a patient.

Relationship rules:
1. Current case owner: full patient/case/message management.
2. Previous referring doctor: complete history and current receiving-doctor conversation are view-only.
3. Appointment doctor: can review the complete patient history, communicate with the patient, and create a new case for that appointment; this does not transfer case ownership.
4. Other doctors with no appointment/referral/current ownership: no patient/case/message access.

Patients can book each appointment with any doctor. The selected doctor receives that appointment, and the patient can communicate with that doctor while the appointment is active.
